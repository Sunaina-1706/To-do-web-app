Task Manager Web App ✨✨
-------------------------
🚀
A lightweight, intuitive web application designed to help users organize, track, and manage their daily tasks efficiently.
-------------------------
#FeaturesTask Names: Assign clear titles to your tasks.

#Description Boxes: Add detailed notes or contexts to each specific task.

#Inline Editing: Double-click or click to update both task names and descriptions instantly.

#Check Button: Mark tasks as complete or incomplete with a single click.

#Delete Button: Permanently remove tasks from your list when they are no longer needed.

-------------------------
Tech Stack
----------------
Frontend: HTML5, CSS3, JavaScript (ES6+)Icons: LuicdeIcons and Alerts using SweetAlerts with Tailwind CSS
